# 하폴 hapole

**1인 회사를 AI 직원들과 운영합니다.**

디자이너로 시작해서 지금은 브랜드 여러 개를 혼자 굴립니다. 혼자지만 혼자가 아닙니다 - PM, 재무, QA, 마케팅, CS까지 역할을 나눈 AI 에이전트 조직이 실무를 나눠 맡고, 저는 결정만 합니다. 그 과정을 하폴이라는 이름으로 기록합니다.

## 지금 돌아가는 자동화

- **스레드 예약 자동발행** - 초안 작성부터 예약 발행, 토큰 갱신까지. 사람은 검수만
- **아침 브리핑 메일** - 매일 8시, 오늘의 루틴 / 마감 할 일 / 발행 일정이 메일로 도착
- **콘텐츠 발행 캘린더** - 릴스 / 스레드 / 캐러셀 일정을 한 화면에서 관리
- **어제 일한 기록 -> 콘텐츠 소재** - 매일 아침 AI가 전날 작업 로그를 읽고 콘텐츠거리를 보고
- **블로그 자동 발행 파이프라인** - 원고만 쓰면 발행까지 손 뗀 채로
- **회계 / CRM 자동화** - 거래명세서 캡쳐 한 장이면 장부 기록 끝
